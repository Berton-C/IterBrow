Requires: LM Studio server running, "Enable CORS" is not needed here (Electron talks to it directly, not via a web page's fetch), context length ≥ 32768, and tool_choice="required" support (llama.cpp engine).
State — Export / Import / Reset
Export saves Iter's accumulated memory, vector store, backups, and knowledge files (not the tool/transformation code) to a zip you choose. Import restores that state from a zip (stopping Iter first if it's running). Reset permanently deletes all accumulated state and starts fresh — your tools/transformations code is never touched by any of these.
Terminal & Files
Browse and edit files under iter/, and run shell commands in a real bash process rooted there. This is a plain (non-pty) shell — interactive full-screen programs like vim or a bare python3 REPL won't render correctly; use the ^C button to recover if a command hangs.
